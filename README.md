
# Sonder India : A Travel Discovery Website

## Project Overview

Sonder India is a responsive, luxury-inspired travel website
that celebrates the landscapes, culture, and destinations of India.

## Purpose and Target Audience

The purpose of this project is to help users discover travel
destinations across India in an attractive and easy-to-use format.

The target audience includes travel enthusiasts, students,
and people looking for inspiration for their next trip.

## Features

- Editorial-style landing page
- Destination cards featuring places across India
- Interactive image carousel
- Favorite destinations list
- Responsive navigation menu for mobile screens
- Responsive layout for desktop, tablet, and mobile devices
- Smooth scrolling and hover effects

## Technology Stack

- HTML — page structure and content
- CSS — styling, grid layouts, animations, and responsiveness
- JavaScript — carousel, favorites, and mobile navigation
- Google Fonts — typography
- Unsplash — travel photography
- GitHub Pages — website deployment


## How to Run Locally

1. Download or clone this repository.
2. Open the project folder in WebStorm.
3. Open index.html in a browser, or use WebStorm's
   built-in preview or browser options.
4. Make sure you have an internet connection for the
   externally hosted photographs and fonts.

No backend, database, or package installation is required.
